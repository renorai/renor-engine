# Política de segurança

*Esse arquivo foi traduzido. Em caso de diferença, vale a versão em inglês!*

## Como relatar uma vulnerabilidade

Relate problemas de segurança de forma privada por meio do sistema de comunicação privada de vulnerabilidades do GitHub:

https://github.com/renorai/renor-engine/security/advisories/new

Não abra uma issue pública para vulnerabilidades como exposição de segredos, bypass de autenticação ou autorização, exposição insegura da rede ou vazamento de dados.

Se possível, inclua:

- a versão ou o commit afetado;
- as etapas para reproduzir o problema;
- o impacto, incluindo se o conteúdo das notas, os fatos armazenados na memória ou os caminhos de arquivos locais podem ser expostos.

## Versões com suporte

As correções de segurança são aplicadas somente à versão mais recente da branch `main`.
